# Реалізація

Проєкт об'єднує три завдання з репозиторію:

* [README.md](README.md) — токенізація тексту та підготовка датасету для ML (основа проєкту);
* [README_LITCRITIC.md](README_LITCRITIC.md) — стилістичний аналіз художніх текстів, працює поверх токенізатора;
* [Syllabls.md](Syllabls.md) — клас «Слово» та поділ українських слів на склади для переносу.

## Збірка та запуск

Потрібні Java 17+ та Maven.

```bash
mvn test        # запуск unit-тестів
mvn package     # збірка jar
java -cp target/classes tokenization.Application
```
