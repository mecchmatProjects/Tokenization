# Модуль токенізації

Модуль містить стратегії розбиття тексту на токени. Наразі він ще не повністю
допрацьований, але базовий інтерфейс `TokenizerStrategy` вже сформовано:
метод `tokenize(const std::string& text) const` повертає `std::vector<Token>`.
Для створення стратегії передбачено `TokenizerFactory::create(TokenizerType)`.

Є реалізації `WhitespaceTokenizer` (розбиття за пробільними символами) та
`WordPunctuationTokenizer` (виділення слів, чисел і пунктуації). Остання
стратегія, `RuleBased`, яка має враховувати правила токенізації, ще потребує реалізації.

Щоб не затримувати інтеграцію з іншими модулями, фабрика тимчасово повертає
`MockTokenizer` для всіх передбачених типів: `Whitespace`, `WordPunctuation`
та `RuleBased`. Невідомий тип спричиняє `std::invalid_argument`.
Мокова стратегія ігнорує вхідний текст (зокрема й порожній) та щоразу повертає
однакові токени за замовчуванням:

| Текст | Тип | Позиція | Номер речення |
| --- | --- | --- | --- |
| `Hello` | `Word` | 0 | 1 |
| `world` | `Word` | 1 | 1 |
| `42` | `Number` | 2 | 1 |
| `!` | `Punctuation` | 3 | 1 |

У всіх токенів `tokenId` дорівнює `-1` (ідентифікатор ще не призначено).
Ці значення є тимчасовими тестовими даними, а не результатом обробки тексту.
Після завершення останньої стратегії `RuleBased` мокове повернення буде прибрано,
і фабрика створюватиме відповідну обраному типу стратегію.

## Використання

```cpp
#include "tokenization/TokenizerFactory.h"

auto tokenizer = TokenizerFactory::create(TokenizerType::WordPunctuation);
auto tokens = tokenizer->tokenize("Довільний текст");
// Тимчасово повертає: Hello / world / 42 / !
```

## Збирання

Потрібні C++14 або новіший, CMake 3.14+ та Git. Для наявних стратегій
використовується `utf8proc` v2.10.0; CMake завантажує залежність під час першого
налаштування.
